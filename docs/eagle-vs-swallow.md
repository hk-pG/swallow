# Eagle 基本機能 vs Swallow（現行 main）

比較日: 2026-11-13  
Swallow 基準: `origin/main` @ `dcaa38d`（#185 マージ後）  
Eagle 基準: 一般に知られるデスクトップ版の「基本機能」（公式ドキュメント等で未確認の細目は「未確認」）

入口: [HANDOFF.md](./HANDOFF.md) / 優先度の要約: [roadmap.md](./roadmap.md)  
**受け入れ・優先度の正本は GitHub Issue**（本表はコードとマージ済み PR に基づくスナップショット）。

## 前提

- 比較対象は Eagle の**基本機能**と Swallow の**現行 main**（α で入ったフォルダ UI・タグ UI・右クリック抑止・App シェル分割に加え、β で main に入った P1/P2 機能一式を含む）。
- Chrome 拡張は**別リポジトリ予定**（#12 OPEN）。本リポにはデスクトップ向けローカル HTTP API のみある。
- Eagle 側で一次情報を本調査で確認していない項目は変更・推測せず「未確認」とする。

## 部分・不足（現状の事実）

ロードマップや未実装の約束は載せない。GitHub Issue の状態は調査時点の事実のみ。

| 判定 | 項目                 | 事実（根拠）                                                             |
| ---- | -------------------- | ------------------------------------------------------------------------ |
| 部分 | タグ UX              | サイドバー絞り込みは単一タグ。Eagle 側のタグ色等は未確認                 |
| 部分 | 検索                 | EXIF（カメラ・撮影日・GPS 等）は UI 上未対応（`AdvancedSearch.tsx`）     |
| 部分 | Quick Look           | PDF 等は `packages/shared/src/preview/previewKind.ts` でプレビュー対象外 |
| 部分 | キーボード           | ショートカットのユーザー設定 UI なし                                     |
| 不足 | Chrome 拡張          | 本リポに実装なし（#12 OPEN、[HANDOFF.md](./HANDOFF.md)）                 |
| 不足 | Eagle ライブラリ移行 | インポートコードなし（#57 OPEN）                                         |
| 不足 | クラウド同期         | 実装なし（[roadmap.md](./roadmap.md)）                                   |

α 到達済みの骨格: [alpha-scope.md](./alpha-scope.md)、[#45](https://github.com/hk-pG/swallow/issues/45)。β で main に入った代表: #34–#35、#49–#56、#58／#167、#164–#165、#176（計測）、#184–#185。
