# Eagle 基本機能 vs Swallow（現行 main）

比較日: 2026-10-18  
Swallow 基準: `origin/main`（`#48` タグ UI マージ後）  
Eagle 基準: 一般に知られるデスクトップ版の「基本機能」（製品版の細目は未検証のものは「要確認」）

入口: [HANDOFF.md](./HANDOFF.md) / 優先度の要約: [roadmap.md](./roadmap.md)

## 前提

- 比較対象は Eagle の**基本機能**と、Swallow の**現行 main**（α で main に入った #41 フォルダ UI・#42 右クリック抑止・#47 App シェル分割・#48 タグ UI を含む）。
- Chrome 拡張は**別リポジトリ予定**で α 外（#12）。本リポにはデスクトップ向けローカル HTTP API のみある。
- α 外の #34（階層取り込み）・#35（設定ファイル拡張）は表で明記する。
- Eagle 側で公式仕様をこの調査では開いていない項目は捏造せず「要確認」とする。

## 比較表

| 機能領域                                       | Eagle                          | Swallow（現行 main）                                                                         | 判定                    |
| ---------------------------------------------- | ------------------------------ | -------------------------------------------------------------------------------------------- | ----------------------- |
| ライブラリ作成・開く・最近使ったライブラリ     | あり                           | `create` / `open` / `restore` / `recent`（#3）                                               | 充足                    |
| フォルダ（階層・作成・移動・割り当て）         | あり                           | ドメイン + サイドバー UI（#7 / #22 / #41）                                                   | 充足                    |
| タグ・タググループ・付与・絞り込み             | あり（色付き等は要確認）       | バックエンド + 管理 UI・付与・単一タグ絞り込み（#8 / #24 / #48）。複数タグ一括編集 UI は弱い | 部分                    |
| スマートフォルダ（ユーザー定義の保存済み検索） | あり                           | 固定スマートビューのみ。ユーザー定義ルールは未実装                                           | 不足                    |
| インスペクター（メタデータ表示・編集）         | あり                           | 名前・注釈・URL・星・タグ・フォルダ（#6）                                                    | 充足                    |
| クイックルック / 原寸プレビュー                | あり（スペース等・要確認）     | グリッドサムネイルのみ。フルサイズ Quick Look なし                                           | 不足                    |
| インポート（ファイル選択・DnD）                | あり                           | ファイルピッカー + DnD（#4）。画像系 + PDF                                                   | 充足                    |
| インポート（フォルダ階層の再現）               | あり（要確認）                 | 未実装（#34・**beta 予定 / α 外**）                                                          | 不足                    |
| テキスト検索                                   | あり                           | 名前・注釈・タグ（#9）。高度演算子・EXIF 検索なし                                            | 部分                    |
| お気に入り（専用コレクション / ビュー）        | あり                           | 星評価 0–5 はあるが「お気に入り」専用ビューなし                                              | 部分                    |
| カラーラベル                                   | あり                           | メタデータ・UI とも無し                                                                      | 不足                    |
| 星評価                                         | あり（要確認: 段数）           | 0–5、インスペクターで編集                                                                    | 充足                    |
| 注釈 / メモ                                    | あり                           | `annotation` フィールドあり                                                                  | 充足                    |
| 複数選択・範囲選択                             | あり                           | クリック / Shift / Cmd-Ctrl、矢印・全選択（#13）                                             | 充足                    |
| ゴミ箱（論理削除・復元・完全削除）             | あり                           | `trash` / `restore` / `purge` + 確認 UI（#10）                                               | 充足                    |
| キーボードショートカット（基本）               | あり                           | 選択・Delete 等の固定ショートカット（#13）。カスタムは未実装                                 | 部分                    |
| 右クリックメニュー                             | カスタムメニューあり（要確認） | 本番は既定メニュー抑止のみ（#33 / #42）。独自は α 対象外                                     | 部分                    |
| サムネイル・グリッド一覧                       | あり                           | グリッド + オンデマンドサムネ（#5）。リストビュー・ズーム UI なし                            | 部分                    |
| ブラウザ拡張（Web から保存）                   | あり                           | **本リポに無し**。別リポ予定・**α 外**（#12）。HTTP API のみ（#11）                          | 不足（α 外）            |
| 拡張連携用ローカル API                         | 拡張向け受信（要確認）         | `127.0.0.1:41600`（#11）                                                                     | Swallowのみ（拡張待ち） |
| ユーザー設定の永続化                           | あり（要確認）                 | `settings.json` は `recentLibraries` のみ。拡張は #35・**beta**                              | 部分                    |
| Eagle ライブラリ移行インポート                 | 自形式                         | 未実装                                                                                       | 不足                    |
| 動画・フォント等の高度プレビュー               | あり（要確認）                 | 画像中心。高度プレビューなし                                                                 | 不足                    |
| クラウド同期                                   | あり（要確認）                 | なし（対象外寄り）                                                                           | 不足（対象外）          |
| App シェル分割                                 | —                              | #44 / #47 で main 取り込み済み                                                               | Swallowのみ             |

判定の目安: **充足** = Eagle 基本として一通り使える / **部分** = 核はあるが UX・範囲が狭い / **不足** = 基本相当が無い / **Swallowのみ** = Eagle に無い（または比較対象外の）Swallow 側の点。
